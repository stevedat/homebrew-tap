# Homebrew Tap for Nido Ecosystem (macOS)

Kho công thức Homebrew chính thức cho các ứng dụng macOS trong hệ sinh thái Nido:
- **NidoOffice** — Bộ ứng dụng văn phòng AI Local-First (Docs, Sheets, Slides, PDF) dành cho macOS (`arm64` & `Intel x64`).
- **Sen Việt (VieLotusIM)** — Bộ gõ tiếng Việt thuần Apple Native (`InputMethodKit`) dành cho macOS.

---

## 🚀 Cài đặt nhanh qua Terminal

### 1. Cài đặt NidoOffice
```bash
brew install --cask stevedat/tap/nidooffice
```

### 2. Cài đặt Sen Việt (VieLotusIM)
```bash
brew install --cask stevedat/tap/vielotus
```

### 3. Cài đặt VieLotus Lab (Bộ chẩn đoán & đo đạc sự kiện gõ)
```bash
brew install --cask stevedat/tap/vielotus-lab
```

---

## 🔄 Cập nhật phiên bản mới
```bash
brew update
brew upgrade --cask nidooffice vielotus
```

---

## 🗑️ Gỡ cài đặt
```bash
brew uninstall --cask nidooffice
brew uninstall --cask vielotus
```
