# Homebrew Tap for Sen Việt (VieLotusIM)

Kho công thức Homebrew chính thức cho **Sen Việt (VieLotusIM)** — Bộ gõ tiếng Việt thuần Apple Native (`InputMethodKit`) dành cho macOS.

---

## 🚀 Cài đặt nhanh qua Terminal

### 1. Cài đặt Sen Việt (VieLotusIM)
```bash
brew install stevedat/tap/vielotus
```

### 2. Cài đặt VieLotus Lab (Bộ chẩn đoán & đo đạc sự kiện gõ)
```bash
brew install stevedat/tap/vielotus-lab
```

---

## 🔄 Cập nhật phiên bản mới
```bash
brew update
brew upgrade vielotus
```

---

## 🗑️ Gỡ cài đặt
```bash
brew uninstall --cask vielotus
```
